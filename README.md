# 🍺 jakeasaurus Homebrew Tap

## ⚡ Electric Homebrew Formulas ⚡

A collection of Homebrew formulas for synthwave-inspired developer tools.

### 🌆 Available Formulas

- **lazytodo** - A synthwave TUI wrapper for todo.txt with electric vibes

## 🚀 Installation

First, add the tap:

```bash
brew tap jakeasaurus/tap
```

Then install any formula:

```bash
brew install lazytodo
```

## 📦 Formula List

| Formula | Description | Version |
|---------|-------------|---------|
| `lazytodo` | ⚡ Synthwave TUI for todo.txt | v0.2.0+ |

## 🎆 Usage

After installation, all tools will be available in your PATH:

```bash
# Start the neon todo experience
lazytodo
```

## 🛠️ Development

To update formulas or contribute:

1. Fork this repository
2. Make your changes to `Formula/*.rb`
3. Test locally: `brew install --build-from-source ./Formula/name.rb`
4. Submit a pull request
